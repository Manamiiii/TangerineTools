# 洛克王国模型服务配置

洛克王国扫描纠错、收集记录检查和性格解释共用一套 OpenAI Chat Completions 兼容配置。模型只处理用户明确触发时所需的受限内容，不能自动改写正式资料、性格分档或收集记录。

核心功能和本地 OCR 不需要模型或 API Key。浏览器直接请求供应商；供应商必须允许跨域访问（CORS），并可能按其规则收费。

## 配置入口

在精灵扫描、收集记录智能检查或性格推荐解释界面打开「洛克王国模型服务」。可选择智谱、DeepSeek、MiniMax、OpenAI 或自定义兼容接口，并填写服务地址、模型 ID 与 API Key。

建议先使用供应商文档提供的默认接口与模型；自定义地址必须是可信的 HTTPS 服务。保存后用不敏感的单条记录测试，再用于批量检查。

## 本地存储边界

- 供应商、接口地址和模型 ID 保存在浏览器 `localStorage`。
- API Key 保存在 `sessionStorage`；浏览器恢复会话时可能恢复会话数据，共享设备使用后应清空 Key 并保存。
- 配置不进入 Dexie、JSON 备份、诊断文件或正式预置。
- 请求结果只进入当前页面的有界内存缓存；写入业务数据前仍需用户确认。

## 供应商说明

- 智谱、DeepSeek、MiniMax 与 OpenAI 使用各自官方 Chat Completions 兼容地址。
- MiniMax 请求温度使用大于零的值，以符合其文本接口约束。
- 自定义供应商需要兼容 `POST /chat/completions` 的请求与响应结构。

「清空 Key 输入」只清空表单，点击「保存配置」后才会清除当前供应商的已存 Key。

不要在共享设备保存 Key，也不要把包含隐私的原始截图或整份个人数据发送给外部模型。
