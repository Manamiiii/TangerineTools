# 洛克王国世界精灵扫描回归基线

## 用途

本文记录固定手机视频的用户确认结果、性能基线和自动回归契约。扫描器修改必须以这里的确认值和版本化截图为准，不得用低置信 OCR 覆盖确认结果。

固定输入规格为 3200 × 1440、24 fps、横屏 HEVC MP4。基准截图保存在 `docs/assets/rock-kingdom-scanner/baseline-3200x1440/`，文件名包含原始顺序和时间点；原始视频不进入仓库。

## 性能与数量基线

- 智能抽帧检查 318 个时间点，步长约 0.30 秒；
- 抽帧保留 55 张，耗时 163.7 秒；
- 批量识别 55 张，耗时 22.4 秒；
- 原第 25、26 张是同一画面，必须只保留一张；
- 55 张均自动关联图鉴，没有“完全未匹配”或“同名形态待选择”；
- 55 张图鉴名及确认字段全部通过。

性能数字用于识别明显退化，不作为跨浏览器的硬性失败门槛。数量、顺序和字段结果属于硬性回归约束。

## 自动回归覆盖

`scripts/tests/rock-kingdom-scanner.test.mjs` 使用版本化截图验证字段裁切、字形模板、头像选择、性别颜色和通用匹配门槛。模板维护数据位于 `scripts/rock-kingdom-scanner/data/`。

当前覆盖：

- 18 种性格、15 种血脉、特长“奇袭”和名称“燃薪虫”的固定字形；
- 11 种稀有外观及“无”和九种伙伴标记；
- 47 张具有明确选中白圈的头像样本，其余 5 张不使用弱选中证据；
- HEVC seek 后等待目标帧真正呈现；
- 切换失败、重复画面和连续同种不同个体的区分；
- 自定义名“梦梦”与图鉴名并存；
- 板板壳、地鼠、鸭吉吉等同名形态的等级、星级、性格和六维公式；
- 罗隐性别符号在渐显状态下仍识别为“公”；
- 头像模板标签必须存在于正式图鉴资料。

`npm run check:scanner:templates` 校验生成素材与截图来源一致；只有显式执行 `npm run apply:scanner:templates` 才更新素材。

## 回归口径

扫描器变更至少检查：

1. 去重后仍保留 55 张，时间点没有非预期漂移；
2. 图鉴名、性格、血脉、外观、特长、伙伴标记和性别符合确认值；
3. 没有新增完全未匹配、同名形态待选择或错误自动关联；
4. 抽帧总耗时、识别总耗时、平均值和中位数没有明显退化；
5. 出现差异时直接检查对应版本化截图，不用低置信 OCR 修改本基线。
