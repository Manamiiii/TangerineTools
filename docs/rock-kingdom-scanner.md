# 洛克王国世界精灵扫描录入

## 定位

精灵扫描录入是洛克王国世界「收集记录」中的场景专用入口。用户界面直接使用精灵、性格、血脉、特长和外观等游戏语义；帧提取、比例裁切、OCR 和候选匹配由独立模块承担，后续有明确的第二个扫描场景时可以复用这些底层能力。

扫描器只读取用户主动选择的本地截图或视频。它不控制游戏、不发送键鼠事件、不读取游戏进程，也不使用连点、宏或脚本切换精灵。

## Windows 采集

1. 在游戏里打开精灵总览页。
2. 按 `Win + Alt + R` 开始 Xbox Game Bar 录制，手动逐只切换精灵并让每只精灵停留约 2 秒；再次按快捷键结束录制。
3. 默认录像目录是“此电脑 → 视频 → 捕获”，通常对应 `%USERPROFILE%\Videos\Captures`。
4. OBS 录像使用“设置 → 输出 → 录像路径”中配置的位置。
5. 在收集记录中打开「扫描录入」，选择录像或一批截图。视频可以按固定秒数抽帧，也可以拖到目标位置后只添加当前画面。
6. 删除切换动画和重复帧，执行 OCR，并逐条确认后写入收集记录。

视频、截图、抽取帧和 OCR 文本只存在于当前页面内存中；原始媒体和抽取帧不写入 IndexedDB。关闭扫描弹窗后页面释放对应的本地对象 URL。

## 采集字段

扫描器关注：

- 精灵名称，对应收集记录的精灵引用；
- 性格；
- 第二层系别区域显示的血脉；
- 特长；
- 性别，由用户复核；
- 外观细分，由用户复核。

雷达图、六维、等级、捕捉精灵球、携带徽章和第一层精灵系别不采集。

外观字段包含“无”和以下 11 种稀有状态：

- 异色；
- 炫彩、异色炫彩；
- 黑白炫彩、黑白异色炫彩；
- S1 炫彩、S1 异色炫彩；
- S2 炫彩、S2 异色炫彩；
- S3 炫彩、S3 异色炫彩。

污染通过血脉文字区分，不属于外观枚举；未确认存在的“异色污染”不进入选项。

扫描器保存 `appearance` 细分值，并同步推导既有 `shiny` / `colorful` 字段。异色炫彩类同时写入两个旧标志，纯炫彩类只写入 `colorful`，异色只写入 `shiny`。这使性格推荐、孵蛋推荐和旧备份仍能读取粗粒度稀有状态。

## 识别与复核

裁切区域使用相对比例，不依赖某个固定像素分辨率。当前比例以用户提供的精灵总览截图为基线；Windows 实机截图用于校准桌面端布局。

OCR 复用应用自带的简体中文离线模型。识别结果与资料库精灵名称、性格选项、血脉选项和特长选项做容错匹配。OCR 与匹配结果都是候选，不直接绕过复核：

- 精灵名称匹配成功的帧才允许写入；
- 外观和性别默认由用户确认；
- 稀有外观图标模板在取得原始游戏截图后补充；
- 低清二次生成图只用于沟通编号，不作为识别素材。

每个确认帧创建一条新的收集记录，符合洛克王国一对多的个体记录模型。扫描不会覆盖或删除现有记录。
