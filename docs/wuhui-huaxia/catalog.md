# 无悔华夏名臣资料与个人收集

本文定义「无悔华夏」场景的目标、最小资料模型和数据来源约束。当前仅归档需求与实施依据，不表示该场景或正式预置已经实现。

## 目标

- 建立覆盖当前游戏版本的名臣资料库，而不是停留在旧攻略或单一 WIKI 的历史名单。
- 记录用户拥有的名臣，并能按时代、品质和类型筛选缺失项。
- 记录每位已拥有名臣是否取得专属装备，以及需要时补充专属等级和备注。
- 允许资料随官方版本增量维护，不要求在首次录入时补齐技能、政策和全部养成明细。

“专属装备”与剧本内采集的“藏品文物”是不同对象。核心收集流程先管理名臣装备栏中的专属；如果需要管理藏品文物，应使用独立资料表和独立收集表，不把两者合并成同一个布尔字段。

## 最小资料模型

### 名臣资料

| 字段 | 类型 | 用途 |
|---|---|---|
| 名称 | 短文本 | 名臣的主显示名称和稳定 id 生成依据 |
| 时代 | 单选 | 例如大宋；用于筛选和完整性核对 |
| 品质 | 单选 | 游戏内品质 |
| 类型 | 单选 | 民生、军事、政治、贤者等游戏内分类 |
| 头像 | 图片 | 可后补，不作为首次建库的阻塞项 |
| 专属名称 | 短文本 | 有可靠来源时填写；未知时保持空白 |
| 来源 | URL | 指向游戏官方公告、游戏内核对记录或补充资料页 |
| 校验状态 | 单选 | 游戏内确认、官方公告确认、辅助来源待核对 |
| 版本备注 | 长文本 | 记录上线批次、联动限制或同名消歧信息 |

### 我的名臣

| 字段 | 类型 | 用途 |
|---|---|---|
| 名臣 | 单条引用 | 引用「名臣资料」中的稳定行 id |
| 是否拥有 | 布尔 | 个人收集状态 |
| 星级 | 数字 | 可选养成信息 |
| 等级 | 数字 | 可选养成信息 |
| 是否获得专属 | 布尔 | 核心专属收集状态 |
| 专属等级 | 数字 | 可选养成信息 |
| 备注 | 长文本 | 自选、培养计划等个人信息 |

该模型使用现有 `catalog` / `owned` / `stock` 通用能力，不需要 Dexie schema 变更。个人记录与正式名臣资料分离；正式资料更新不得覆盖用户填写的个人状态。

## 数据来源

### 完整性基准

游戏内名臣录是当前版本名单和个人拥有状态的最终核对依据。连续截图可用于提取名称、时代、品质、类型和卡片状态；识别结果必须经过人工复核后再进入正式资料或个人收集记录。

不把“找到一张完整的网络表格”作为建库前提。首次资料可以只包含足以管理收藏的最小字段，其他字段按名臣逐步补充。

### 官方增量来源

- [TapTap 无悔华夏官方论坛](https://www.taptap.cn/forum/g212650)：关注“华夏名臣录”“更新公告”“华夏情报站”等官方栏目，用于识别新增名臣和上线批次。
- [好游快爆游戏与版本页](https://www.3839.com/a/117089.htm)：开发者已入驻，适合交叉核对版本发布日期、时代范围和版本更新摘要。

2026 年 7 月 17 日的大宋版本资料声明岳飞、李清照、辛弃疾等 27 位新名臣陆续登场；随后仍有岳飞演化、穆桂英和《绍宋》联动名臣等独立更新。名臣名单因此必须按版本增量维护，不能把“大宋首发名单”视为长期完整名单。

### 辅助资料来源

- [无悔华夏 BWIKI](https://wiki.biligame.com/whrhx/%E9%A6%96%E9%A1%B5) 可补充旧名臣的时代、品质、类型、信物、专属名称和部分养成明细。
- [BWIKI 藏品文物收集条件](https://wiki.biligame.com/whrhx/%E8%97%8F%E5%93%81%E6%96%87%E7%89%A9%E6%94%B6%E9%9B%86%E6%9D%A1%E4%BB%B6) 只用于独立的藏品文物资料，不等同于名臣专属装备。

BWIKI 的旧名臣页、新图鉴页和结构化分类没有完整统一，大宋等近期内容也可能滞后。它是字段补充来源，不是当前完整名录的权威来源。普通攻略帖同样只作为线索；缺少游戏内或官方依据的字段保持空白并标记待核对，不根据历史人物常识或攻略转述推断游戏字段。

## 建库顺序

1. 从游戏内名臣录连续截图建立当前完整名单和个人拥有状态。
2. 人工复核 OCR 结果，建立稳定行 id，并优先填入最小资料字段。
3. 根据官方公告补充上线批次、联动限制和新增名臣。
4. 使用 BWIKI 等辅助来源逐步补充专属名称、头像和非核心明细。
5. 以版本更新为增量入口，新增资料行，不重建或清空用户的收集记录。

首次实施宜选取一个时代或约 10 至 20 位名臣作为样本，验证字段、筛选和个人录入体验后再扩展全量资料。
