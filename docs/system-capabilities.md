# TangerineTools · 系统能力

TangerineTools 是面向个人使用的本地优先多游戏管理应用。它负责游戏资料、个人收集和派生分析；照片、设备与阅读工作流分别属于独立项目。

## 场景与工具

- 首页列出游戏场景，并支持创建、编辑和删除。
- 新建游戏场景可使用资料库 `catalog`、收集记录 `owned` 和统计视图 `stock`。
- 稳定 id 为 `scene-rock-kingdom` 的「洛克王国世界」场景额外提供性格推荐 `nature` 与孵蛋推荐 `breeding`。
- 工具入口按场景能力过滤。其他游戏不会显示依赖洛克王国字段和规则的专项工具。
- 数据中含有 `reader` 工具或 `reading` 类型的场景不进入游戏场景列表，其记录保持原状并可通过首页迁移出口转移。

## 通用游戏管理

### 资料库

- 一个场景可建立多张普通资料表，配置字段、显示方式、排序、搜索、筛选与分页。
- 支持短文本、长文本、图文摘要、数字、图片、单选、多选、布尔、URL、日期、单条引用、多条引用和派生指标视图。
- 行值以字段 `key` 存取；隐藏字段仍可在详情中查看。

### 收集记录

- 收集表复用相同的表、字段和行模型，以 `catalogTables.kind === 'owned'` 区分。
- `collectionMode` 支持同一资料对象保留一条或多条个人记录。
- 批量修改、筛选、分页和统计摘要均不改变 Dexie schema。

### 统计视图

- 从当前场景的普通资料表和收集表选择数据源，按字段分组并叠加数值条件。
- 所有统计均为运行时派生结果，不创建固定统计表。

## 洛克王国世界

- 内置场景、表结构、字段与正式精灵/技能资料由版本化预置维护。
- 性格推荐读取「精灵基础资料」，沿 `skillRefs` 读取「技能资料」，输出推荐、可保留、不推荐及可检查的规则原因。
- 孵蛋推荐根据正式繁育字段和用户收集记录生成最多五对不复用父母的同蛋组候选；后代目标按母方繁育谱系判断。
- 推荐规则可以独立启用和调整优先级，按顺序逐级比较缺异色、缺炫彩、缺异色性别与缺好性格等目标。好性格包含性格推荐中的「推荐」与「可保留」，并按后代目标而不是父母自身判断。
- 稀有外观概览按正式 `speciesGroup` 繁育谱系汇总异色、炫彩、公母覆盖和好性格数量。异色缺口只统计正式资料以 `shiny` / `shinyImage` 确认存在异色形态的谱系；默认展示全部可繁育谱系，并可筛选已有收集的缺口；具体个体仍由图鉴和收集记录管理。
- 收集记录支持精灵扫描、本机 OCR、人工复核、重复提示和可选模型纠错；写入前始终由用户确认。
- 模型可解释确定性结果或整理低置信候选，但不能改写正式资料、性格分档或自动写入收集记录。

正式数据发布规则见 [`data-sources/bwiki-pipeline.md`](data-sources/bwiki-pipeline.md)，性格规则见 [`nature/rules.md`](nature/rules.md)，扫描契约见 [`rock-kingdom/scanner.md`](rock-kingdom/scanner.md)。

## 本地数据与迁移

- 唯一持久存储是浏览器 IndexedDB；数据库名为 `tangerine-tools`，schema 为 v1。
- 全量 JSON 导入采用按 id 增量合并，不清空文件未包含的本地数据。
- 首页检测 `readerState:` 与 `readerPersonalPackage:` 命名空间。存在记录时提供阅读迁移 JSON，供 Tangerine Reading Companion 导入。
- 阅读迁移只复制匹配的 `meta` 记录，不删除源数据，也不包含游戏场景、资料表、收集记录或模型密钥。

详见 [`data-sync.md`](data-sync.md)。

## 明确边界

- 无后端、账号、自动云同步或多租户权限体系。
- 不负责照片、镜头或设备管理。
- 不负责阅读资料包、阅读进度、文学地图或剧透控制。
- 不提供战斗模拟、MCTS、PVP 自动化或属性克制系统。
