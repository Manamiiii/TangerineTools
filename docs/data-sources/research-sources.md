# 外部研究资料源

## 定位

TangerineTools 使用两类资料源：

- **正式结构化源**：BWiki staging / preview / apply 管线负责编号、名称、形态、六维、系别、特性、技能关系等运行时预置字段。
- **外部研究源**：B站、小红书等玩家内容用于理解版本玩法、实战定位、养成路线、队伍作用、机制演示和玩家分歧。

外部研究材料是分析证据，不是正式预置字段。帖子或视频中的主观结论不得直接覆盖 BWiki 正式数据，也不得直接变成性格推荐结果。

## 平台用途

| 平台 | 适合核对的内容 | 使用方式 |
|---|---|---|
| [B站](https://www.bilibili.com/) | 战斗录像、技能演示、首领进化前后差异、养成与配队讲解、明确版本时间的视频攻略 | 记录视频链接、标题、UP 主、发布时间、相关分段时间和可复核画面 |
| [小红书](https://www.xiaohongshu.com/) | 单只精灵图文攻略、一图流、养成面板、队伍组合、版本体验和评论区补充 | 记录笔记链接、标题、作者、发布时间或更新时间、相关图片页和结论摘要 |

平台内容可能需要登录后查看。研究时可以使用用户已经登录的浏览器会话进行人工检索和阅读；不绕过登录、验证码、访问限制或反自动化措施，不批量抓取账号内容、评论和用户信息。

## 证据记录

每次单只精灵研究至少保存以下信息：

1. 精灵名称、形态和研究问题。
2. 来源平台、原始链接、标题、作者和发布时间。
3. B站视频的相关时间点，或小红书笔记的相关图片页 / 正文位置。
4. 可观察事实与作者观点的区分。
5. 内容对应的游戏版本；无法确认版本时明确标记。
6. 与本地六维、特性、技能关系或既有规则的相符点和冲突点。

页面标题、链接和简短摘要可以写入研究结果；视频、图片和长篇正文不复制进仓库。用户确认后的稳定结论写入 `docs/nature/confirmed-results.md`，尚未解决的规则问题写入 `docs/nature/open-issues.md`。

## 采用顺序

同一结论存在多个来源时，按以下顺序判断：

1. 游戏内可复核画面或明确数值。
2. 与当前版本一致、展示完整操作过程的材料。
3. 多个独立作者能够相互印证的结论。
4. 单一作者的分析或评论区观点。

发现外部材料与 BWiki 正式字段冲突时，先作为数据源问题记录并回到 BWiki staging 核对；未经正式 preview / apply 流程，不修改运行时预置。发现多个精灵共同暴露同一推荐规则问题时，按性格推荐工作流请求用户确认后再修改通用规则。

## 最终面板公式资料

最终面板公式属于机制研究结论，不写入 BWiki 正式预置。当前实现使用以下可复核来源：

- [洛克速查 · 速度线](https://roco.pet/speed/)（访问日期：2026-07-27）：页面公开非生命面板公式、性格倍率与个体换算关系，并列出基础速度 120、个体 10、加速性格得到 260 的速度线；该数值与用户在游戏内验证的咔咔鸟结果一致。
- [洛克王国世界 BWiki · 性格计算器](https://wiki.biligame.com/rocom/%E6%80%A7%E6%A0%BC%E8%AE%A1%E7%AE%97%E5%99%A8)（访问日期：2026-07-27）：用于交叉核对性格增减方向与当前版本计算器语境。
- [《洛克王国世界》精灵能力值计算器，dewxin](https://www.cnblogs.com/dewxin/p/19835084)（访问日期：2026-07-27）：记录生命与其余五维的计算表达式，作为生命公式和双层取整的交叉来源。
- [roco-claude · 伤害与能力值计算公式](https://zyx20180209.github.io/roco-claude/data/mechanics/damage_formula.html)（访问日期：2026-07-30）：整理《洛克计算器 2.0》的 60 级满培养能力值公式，交叉核对生命与其余五维的种族值、天分、性格和固定加值分层；页面同时记录基础资质 105 且无额外加成时计算器会比游戏实际高 1 的已知边界。
- [ABC 游戏网 · 洛克王国世界怎么看宠物好坏](https://www.youxiabc.com/p/19186.html)（作者标记为 fan，发布时间：2026-04-06；访问日期：2026-07-30）：记录强化性格从 0 星 10% 起、每星增加 2%，弱化固定 10%，并说明天分随等级和星级成长。
- [ABC 游戏网 · 洛克王国世界怎么改性格](https://www.youxiabc.com/p/18651.html)（作者 Ekko，发布时间：2026-04-03；访问日期：2026-07-30）：记录初始天分为 `7～10`，每升一星增加一份初始值，5 星时为初始值的 6 倍。
- [3DM · 洛克王国世界精灵品质介绍](https://ol.3dmgame.com/gl/336384.html)（来源标记为游侠，发布时间：2026-03-31；访问日期：2026-07-30）：记录一般般、还不错、相当好、了不起天分分别具有 1～3 项加成，因此扫描器在看不到资质弹窗时枚举 1～3 项，而不固定假设三项。

任意等级公式由上述满培养边界和用户提供的固定设备录屏共同校准。录屏中约 `0:05` 的板板壳为 1 级、0 星、胆小，基础六维配合天分生命/魔攻/速度各 `+7` 后精确得到 `48 / 22 / 49 / 43 / 51 / 39`；约 `0:11` 的鸭吉吉（燃了鸭）为 13 级、0 星、警惕，生命/物攻/魔防天分为 `+7 / +8 / +7` 时精确得到 `108 / 62 / 36 / 57 / 46 / 82`；约 `0:19` 的小独角兽为 44 级、0 星、悠闲，魔攻/物防/魔防天分为 `+7 / +7 / +9` 时精确得到 `163 / 55 / 135 / 79 / 84 / 80`。扫描器只把该公式用于本地候选校验，不把录屏结果写入正式预置。

这些社区资料只支撑公式换算；伤害、定位和最终性格推荐仍按本项目的本地规则与审计流程判断。

## 性格攻略与使用率口径

攻略中的“可用”、游戏内使用率和本项目的最终性格分档回答的是不同问题。使用率可能同时包含随机获得、过渡使用、稀有个体保留、待用银镜修改，以及不同版本、玩法与段位的混合样本；除非样本能分离版本、模式、段位、配招和性格修改条件，否则不能从高使用率直接推出该性格最优。

当前用于核对这一口径的公开材料包括：

- [TapTap · 给大家讲一下宠的性格怎么选](https://www.taptap.cn/moment/800696042193420907)（页面标记修改于 2026-05-06；访问日期：2026-07-27；公开页面未显示可核对作者）：作者观点以基础速度 `115` 作为常规抢速起点，同时给速度特性或技能状态留下例外，并强调精灵可能存在多种培养方向。
- [游侠网 · 洛克王国世界恶魔狼性格怎么选](https://gl.ali213.net/html/2026-4/1761317.html)（发布时间：2026-04-08；访问日期：2026-07-27）：文章把开朗列为理想路线，把急躁、天真明确称为未获得完美性格前的过渡选择，可作为“攻略里的可用不等于最终最优”的直接样本。
- [B站专栏动态 · 洛克王国世界 S2 赛季小丑豆豆性格推荐](https://www.bilibili.com/opus/1207365386268311554)（发布者：7881洛手全免手续费；发布时间：2026-05-28；访问日期：2026-07-27）：内容把急躁列为次选抢速路线，但页面带交易推广，且数值口径与已验证公式存在差异，只记录为低可信度的玩家选择样本，不用于修改公式或推荐结论。
- [洛克王国世界 BWiki · 性格](https://wiki.biligame.com/rocom/%E6%80%A7%E6%A0%BC)（页面更新时间：2026-05-13；访问日期：2026-07-27）：只用于确认急躁为强化速度、弱化物防，不提供其是否适合作为最终性格的证据。
