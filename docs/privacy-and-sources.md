# 隐私与第三方内容

## 收藏与备份

- 收藏、资料编辑和场景配置保存在当前浏览器、当前站点的 IndexedDB 中，没有账号服务或自动云同步。GitHub 保存的是项目文件，不是你的浏览器收藏。
- 备份是明文 JSON，包含资料与个人记录。请自行保管；不要把完整备份提交到公开仓库或 Issue。
- 同一浏览器的不同域名、协议或端口，以及不同浏览器配置文件，使用独立站点存储。迁移需先导出再导入。
- 导入前显示新增与覆盖范围；同 ID 整条覆盖，未包含的本地记录保留。没有自动撤销覆盖功能，操作前应保存当前备份。
- 删除场景会删除其中的资料表和收集记录；页面要求确认，但没有回收站。清除浏览器站点数据也会移除收藏。

## 网络请求

- 应用加载从部署站点获取代码、预置资料及 OCR 资源；托管服务可能记录常规访问日志。
- 部分游戏图片来自外部 Wiki 图床，浏览器会向其请求图片。文字记录保存在本机不代表完全没有网络请求。
- 没有埋点、广告或项目自建的用户数据上传服务。
- 可选模型功能只在主动点击后向配置的供应商发送当前功能需要的内容：性格解释发送程序结果；收集智能检查发送选中记录的有界摘要；扫描纠错发送低置信文字及有限候选。原始视频和图片不发送给模型。
- 模型请求附带用户填写的 API Key，供应商需允许浏览器 CORS 请求。只使用可信的 HTTPS 地址；本机模型可用 localhost HTTP。不提供替用户中转或隐藏供应商 Key 的后端。
- 接口和模型设置保存在 localStorage；Key 保存在当前会话的 sessionStorage，不进入 JSON 备份。不要在共享设备使用个人 Key；浏览器会话恢复行为以浏览器为准。

## 扫描素材

用户选择的视频、截图、抽取帧和 OCR 文本在页面内存中处理，不作为媒体写入 IndexedDB。写入的是用户确认的结构化记录。扫描窗口关闭后释放本地媒体 URL。

仓库 `docs/assets/rock-kingdom-scanner/` 内的版本化回归截图来自游戏画面，属于测试素材，不是项目原创图像。公开发行前应逐张复核其中是否含昵称、账号或其他不应公开的信息，以及相应分发权限。
